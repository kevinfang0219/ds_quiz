# 資料結構核心能力測驗系統 💻

這是一個基於 Django 開發的線上測驗平台，專門針對資料結構中的「雜湊表 (Hash Tables)」單元進行特訓。本系統突破傳統紙本測驗限制，導入數位化防弊與演算法，有效提升學習與複習成效。

## 🌟 系統核心亮點
* **客製化測驗模式**：提供 5 題（快速複習）與 10 題（完整測驗）兩種模式供使用者彈性選擇。
* **間隔學習機制 (錯題本)**：系統會自動記錄使用者答錯的題目，並於下一次測驗時「優先抽出」錯題，透過針對性演算法強化學習弱點。
* **難易度視覺化**：後台題目具備分級制度，前端即時動態渲染「綠色(易)、橘色(中)、紅色(難)」標籤，協助使用者評估挑戰性。
* **防作弊抽題機制**：每次測驗不僅從題庫隨機抽題，更會**動態打亂選項順序**，有效防止死背答案。
* **現代化 UI 介面**：採用明亮科技風格，具備玻璃質感卡片與即時互動回饋，並於測驗後提供完整的成績結算與錯題檢討。

## 🛠️ 安裝與執行步驟

請依照以下步驟在本地端環境運行本系統：

**1. 複製專案到本地端**
```bash
git clone https://github.com/kevinfang0219/ds_quiz.git
cd ds_quiz
```

**2. 建立並啟動虛擬環境**
```bash
python -m venv myenv
啟動環境（請依據您的作業系統選擇指令）：

Windows: myenv\Scripts\activate

Mac / Linux: source myenv/bin/activate
```

**3. 安裝必要套件**
本專案的依賴套件已記錄於 `requirements.txt`，請執行以下指令安裝：
```bash
pip install -r requirements.txt
```

**4. 啟動伺服器**
```bash
python manage.py runserver
```

**5. 開始使用**
打開瀏覽器，前往 `http://127.0.0.1:8000/` 即可開始測驗！
